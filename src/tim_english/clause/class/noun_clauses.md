# 名词性从句引导词技巧

## 连词-不当成分

what / whether / if “是否”  

## 副词-不当成分

when / where / how / why / because / Whenever / wherever / however  

## 代词-充当成分

what / which / who / whom / whose / Whatever / whichever / whoever / whomever / whichever  

## 注意

1. **ever = "无论…"** (例：whoever → "无论谁")  
2. **本技巧中充当状语的词也视为不当成分**  
3. **who 当主语，whom 当宾语**
