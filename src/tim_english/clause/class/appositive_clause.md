# 同位语从句

## 同位语从句 vs 定语从句

### 定语从句

I have a dream **that sounds interesting**.

### 同位语从句

I have a dream **that you pass the exam**.

#### 区别

- 定从 - 修饰限定
- 同从 - 内容说明（从句把引导词前面那个词的内容说出来）

### 同位语从句做题技巧

空格前看到 news, idea, thought, reason, dream, fact, promise, suggestion 等，立刻怀疑考同位语从句，用 that。

## 随堂练习

We are delighted at the news _____ our team has won the first prize.
::: details answer
that
:::

The manager put forward a suggestion ______ we should have an assistant. There is too much work to do.
::: details answer
that
:::
