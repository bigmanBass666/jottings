# 比较级和最高级

## intro

针对形容词和副词

| 原级      | 比较级         | 最高级         |
| --------- | -------------- | -------------- |
| smart     | smarter        | smartest       |
| difficult | more difficult | most difficult |

## 形容词比较级 & 最高级规则  

**元音字母：A, E, I, O, U**

1. ​**直接加 `-er/-est`**  
   - 例：tall → taller → tallest

2. ​**以 `e` 结尾，加 `-r/-st`**  
   - 例：brave → braver → bravest

3. ​**辅音字母 + y 结尾 → 变 `y` 为 `i` + `-er/-est`**  
   - 例：happy → happier → happiest

4. ​**重读闭音节，双写辅音字母 + `-er/-est`**  
   - 例：big → bigger → biggest

5. ​**多音节词 → 前加 `more/most`**  
   - 例：beautiful → more beautiful → most beautiful

## 不规则变化

| 原级   | 比较级 | 最高级 | 中文释义         |
| ------ | ------ | ------ | ---------------- |
| good   | better | best   | 好的             |
| well   | better | best   | 身体健康的       |
| bad    | worse  | worst  | 坏的             |
| ill    | worse  | worst  | 生病的           |
| little | less   | least  | 少的（数量）     |
| much   | more   | most   | 许多的（不可数） |
| many   | more   | most   | 许多的（可数）   |

### 注意事项

1. `well` 作副词时比较级仍是 better/best（例：do better）
2. `ill` 和 `bad` 共用比较级形式，但用法不同：
   - ill → worse → worst（健康状况）
   - bad → worse → worst（一般品质）
3. little/much/many 的用法区分：
   - little → 修饰不可数名词（例：little water）
   - much → 修饰不可数名词（例：much time）
   - many → 修饰可数名词（例：many books）

## 技巧

看到than立刻考虑比较级

## "The more..., the more..."

**语法公式**：  
`The + 比较级 + 主语 + 谓语，the + 比较级 + 主语 + 谓语`  

**示例**：  

- The harder you study, the luckier you will be.  
- The more books you read, the wiser you become.  

## 比较级与最高级对比  

| 类别   | 比较范围   | 标志词       | 示例                                   |
| ------ | ---------- | ------------ | -------------------------------------- |
| 比较级 | 两者对比   | than         | She is **taller** than me              |
| 最高级 | 三者及以上 | the + 形容词 | This is **the most difficult** problem |
