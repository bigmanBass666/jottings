# 情态动词

p167

## 原形&过去时

| 原形    | 过去时 | 中文                    |
| ------- | ------ | ----------------------- |
| Will    | would  | 将会                    |
| can     | could  | 能够                    |
| shall   | should | 应该要做 (=ought to do) |
| may     | might  | 也许                    |
| Have to | had to | 不得不                  |
| must    | -      | 必须                    |

注：must 无过去时。

## 注意

**can't** “不能；不可能”

You can't be Yanzu. Yanzu is so handsome.  
你不可能是彦祖，彦祖是如此的帅。

## 情态动词的用法特点

- 不能单独作谓语
- 后面接动词原形
- 否定通常直接在其后加 not

## 情态动词+have done

May/might have done　　过去也许  
Would have done　　　　本来会做  
Should have done　　　本来应该做  
Ought to have done　　本来应该做  
Could have done　　　本来能够做  

### 注意

**Must have done**  

- 过去一定  
- 对过去事情的**肯定推测**  

它的否定如下  

**can't/couldn't have done**  

- 过去不可能  
- 对过去事情的**否定推测**
