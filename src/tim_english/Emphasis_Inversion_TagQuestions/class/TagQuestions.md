# 反意疑问句

p191

## 格式：陈述句 + 简短的疑问句

- **You can’t do that, can you?**  
- **You can do that, can’t you?**  

## 技巧

- **前否后肯**  
- **前肯后否**  

## 助动词的来源

- 原句若有，则用同类；  
- 若无，则用 **do** 类。

## 随堂练习

Judy hardly joins in any activities, ____ she? ✅  
::: details answer  
does (我看没有助动词, joins是单数且现在时) (虽然但是, 你还要注意一下前后句的否定与肯定关系)
:::

There is not much news in today's paper, ____ there? ✅  
::: details answer  
前否后肯, 且有助动词 is, 所以:  
is
:::
