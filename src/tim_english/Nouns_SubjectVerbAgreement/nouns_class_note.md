# 名词复数

p40

## 可数名词

- **定义**：可数名词是可以用数目计数，能被基数词（如one，more than one等）或其相当的词（如many/few/a few等）修饰的名词。
- **用法**：
  - 可以有复数形式；
  - 可直接在其前使用不定冠词或数词；
  - 可受these，those，few，a few，many，a good/great many，a great/good number of等修饰。例如：
    - There are many things to be done.
    - A large number of students are girls.

## 不可数名词

- **定义**：不可数名词是不可用数目计数的名词，不能被基数词（如one，more than one等）或其相当的词修饰。
- **用法**：
  - 通常没有复数形式；
  - 其前不可直接用不定冠词或数词；
  - 可用（a）little，much，a great deal of，a lot of，plenty of，a large amount of，a large quantity of，some，any等修饰；
  - 要表示数量时，不可在前面直接加数词，而要用a piece of之类的结构。

## 名词复数规则变化

- **元音字母**：A、E、I、O、U
- **规则**：
  1. 以字母s，sh，ch，x结尾和以辅音字母+o结尾的名词变复数时加-es，如：buses，foxes，potatoes；
  2. 元音字母加-o的名词直接加-s，如：radios，zoos；
  3. 大部分以字母f或fe结尾的名词变复数形式，要把f或fe改为v再加-es，如：leaf-leaves，knife-knives；
  4. 以辅音字母+y结尾的名词变复数形式时，要把y变为i，再加-es，如：baby-babies，country-countries。

## 名词复数不规则变化

1. 改变单数名词中的元音字母，如：man-men，woman-women；
2. 单、复数相同，如：sheep，deer，means，works；
3. 特殊形式，如：child-children，tox-oxen；
4. 表示某国人的名词单复数形式因习惯而异：
   - 单复数形式相同，如：Chinese，Japanese；
   - 词尾加-s，如：two Russians，two Germans；
   - 变man为men，如：Englishmen，two Dutchmen。

## 名词复数特殊变化

1. 两部分都变复数，如：lookers-on，betweens；
2. 主体后或整体后变复数，如：sports meeting（运动会）；
3. 表示不同类别，如：fruits（各种水果），teas（各种茶）；
4. 本来就自带“s”，如：maths（数学），physics（物理学），politics（政治）。

## 技巧

提示词若为名词，若不考词性变化，通常考复数。
