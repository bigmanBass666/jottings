# 完形填空

《复习全书·新题型》P241  

## 变革年 2015 年  

前-20 空-0.5 分共 10 分  
后到 2021-15 空-1 分共 15 分  
现-2022-15 空-2 分-30 分  

## 考点变化  

前-重词汇搭配语法轻逻辑  
后-重逻辑轻词汇搭配语法  

## 做题技巧  

- 无需通读全文，直接按顺序往下做题  
- 不要关注不懂的表达，要关注懂的表达
- 不要自作多情，做题讲证据
- 圈出文章与选项相关联的表达，常为答案
- 圈出文章与选项相同/相近/相反的表达，常为答案
- 跳过毫无头绪的题
- 小技巧1-蒙题先蒙C再蒙B
- 小技巧2-太陌生的选项本般不选师钟添
