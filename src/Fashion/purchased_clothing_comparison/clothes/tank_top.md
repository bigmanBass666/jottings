### L

| 颜色 | 衣长     | 腰围 | 胸围 |
| ---- | -------- | ---- | ---- |
| 黑   | **53.5** | 76   |      |
| 灰   | 49.7     | 78   | 80   |
| 白   | 50.3     | 79.2 | 83   |

#### 黑

- 这个衣长不能再短了, 只能比这个长 `53.5`
- 从视频里来看, L 码视觉效果最好, 因为腰收紧了, 衣长更短, 但是第一人称看着有些过于紧致擦边了(多日后补充: 其实也还好, 没那么夸张)
  > 胸围`82cm`, 比红背心小`2cm`
- 衣长手工测量为`53.5`, 挺合适的, 算是完美衣长了, 只有在一些特别刁钻的角度下才会露肚子

#### 白&深灰

白和深灰这 2 件都不太行, 太短了, 腰围也偏大了些, 无效收腰 🙅‍♂️

### XL

- 第一人称看着正常, 毕竟胸围`88cm`比红背心大了`4cm`
